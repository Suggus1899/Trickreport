# Identidad de marca Trickreport

La marca combina seguimiento claro de solicitudes con una señal de avance. El símbolo SVG usa una **T** geométrica y un trazo de verificación que sugiere progreso.

| Uso | Color | Token |
| --- | --- | --- |
| Primario claro | Indigo `#4F46E5` | `--accent` |
| Secundario claro | Verde `#047857` | `--green` |
| Fondo oscuro | Azul tinta `#0B1220` | `--background` en tema oscuro |
| Primario oscuro | Indigo claro `#818CF8` | `--accent` en tema oscuro |
| Secundario oscuro | Verde claro `#34D399` | `--green` en tema oscuro |

Tipografía: Public Sans para la interfaz y Space Mono para identificadores técnicos. Las aplicaciones usan el SVG en `apps/*/public/trickreport-mark.svg`; conservar proporción y contraste, y no añadir texto dentro del símbolo.

El uso actual entrega el mismo símbolo con el nombre tipográfico `trickreport`. El catálogo de versiones, favicon y exportaciones de alta resolución queda pendiente.
